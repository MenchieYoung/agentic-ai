# Module 3: Tool Use and Function Calling

## Overview
This module covers how agents interact with external tools and APIs through function calling. You'll learn to design tool interfaces, handle tool responses, and build agents that can access real-world information.

## What's Available

### ✅ Official Course Materials
- **C1M3_Assignment.ipynb**: Official graded programming assignment
- **demos/ugl1/**: Ungraded lab on basic function calling
- **demos/ugl2/**: Ungraded lab on advanced tool integration

### ⚠️ AI-Generated Materials
- **quiz.md**: Study aid generated by AI to help reinforce concepts

### 📋 Supporting Files
- **instructions.md**: Assignment guidelines
- **C1M3_Assignment_Solution.ipynb**: Reference solution (view only after attempting)

## Learning Path

1. **Watch Module 3 lecture videos** on the course platform
2. **Complete ungraded labs** in the demos/ folder:
   - Start with `demos/ugl1/M3_UGL_1.ipynb` (basic function calling)
   - Then try `demos/ugl2/M3_UGL_2.ipynb` (advanced integration)
3. **Work on graded assignment**: `C1M3_Assignment.ipynb`
   - Implement tool calling logic
   - Handle tool responses and errors
   - Submit for grading
4. **Optional**: Review quiz.md to test your understanding

## Key Concepts
- Function/tool schema definition
- Parsing function calls from LLM responses
- Error handling and retries
- Tool result integration
- When to use tools vs. direct LLM responses

## Estimated Time
- **Lecture videos**: 45-60 minutes
- **Ungraded labs**: 1-1.5 hours
- **Graded assignment**: 1-2 hours
- **Total**: 2-3 hours

## Tips
- Pay attention to function schema format (JSON Schema)
- Test your tools independently before integrating with the agent
- Handle edge cases: missing parameters, API errors, invalid responses
- Don't look at the solution file until you've attempted the assignment
