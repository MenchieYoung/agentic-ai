# Module 5: Multi-Agent Systems

## Overview
This module introduces multi-agent coordination, where multiple AI agents collaborate to solve complex tasks. You'll learn to design agent teams, implement coordination patterns, and use frameworks like crewAI.

## What's Available

### Course-Derived Copies
- **C1M5_Assignment.ipynb**: Learner assignment copy with exercise placeholders
- **demos/ugl1/**: Ungraded lab on basic multi-agent coordination
- **demos/ugl2/**: Ungraded lab on advanced multi-agent patterns

### ⚠️ AI-Generated Materials
- **quiz.md**: Study aid generated by AI to help reinforce concepts

### 📋 Supporting Files
- **instructions.md**: Assignment guidelines
- **C1M5_Assignment_Solution.ipynb**: Reference solution (view only after attempting)

## Learning Path

1. **Watch Module 5 lecture videos** on the course platform
2. **Complete ungraded labs** in the demos/ folder:
   - Start with `demos/ugl1/M5_UGL_1.ipynb` (basic coordination)
   - Then try `demos/ugl2/M5_UGL_2.ipynb` (advanced patterns)
3. **Work on graded assignment**: `C1M5_Assignment.ipynb`
   - Design a multi-agent system
   - Implement agent coordination
   - Run `python unittests.py` from this directory; it uses fake model responses and makes no API or network calls
   - Run the notebook normally afterward to evaluate the live workflow
4. **Optional**: Review quiz.md to test your understanding

## Key Concepts
- Agent roles and responsibilities
- Communication and coordination patterns
- Task decomposition and delegation
- Consensus and conflict resolution
- crewAI framework and similar tools
- When to use multi-agent vs. single-agent approaches

## Estimated Time
- **Lecture videos**: 60-75 minutes
- **Ungraded labs**: 1.5-2 hours
- **Graded assignment**: 2-3 hours
- **Total**: 3-4 hours

## Tips
- Start simple: design clear roles before adding complexity
- Test individual agents before coordinating them
- Pay attention to information flow between agents
- Consider failure scenarios: what if one agent fails?
- Apply evaluation techniques from Module 4 to assess agent collaboration
- Don't look at the solution file until you've attempted the assignment
