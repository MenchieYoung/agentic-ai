# Module 2: Reflection Pattern

## Overview
This module introduces the reflection pattern, where agents review and improve their own outputs. You'll learn how to implement self-evaluation and iterative refinement in AI systems.

## What's Available

### ✅ Official Course Materials
- **C1M2_Assignment.ipynb**: Official graded programming assignment
- **demos/chart_generation/**: Ungraded lab on chart generation with reflection
- **demos/sql_reflection/**: Ungraded lab on SQL query refinement

## Learning Path

1. **Watch Module 2 lecture videos** on the course platform
2. **Complete ungraded labs** in the demos/ folder:

## Key Concepts
- Self-evaluation and critique
- Iterative refinement loops
- Quality metrics for agent outputs
- When to apply reflection patterns
